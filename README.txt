Очищенная версия проекта ESTELAR.

Структура:
- index.html — основная страница магазина
- assets/css/styles.css — стили витрины
- assets/js/app.js — клиентская логика, загрузка meta/catalog/order API
- assets/js/item-details.js — конфиг API base
- assets/fonts — локальные шрифты
- assets/images — изображения и иконки товаров
- assets/misc — исходные вспомогательные ресурсы
- backend — Go Fiber backend с подготовкой под Supabase/Postgres
